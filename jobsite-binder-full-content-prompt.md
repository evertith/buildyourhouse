## SECTION 8: QUICK REFERENCE GUIDES (10 pages)

### 8.1 Residential Code Quick Reference (3 pages)

**Common Code Requirements:**

**Stairs:**
- Max riser height: 7.75"
- Min tread depth: 10"
- Max variance: 3/8"
- Handrail height: 34-38"

**Guardrails:**
- Required when drop >30"
- Minimum height: 36" residential
- Sphere test: 4" max opening

**Outlets:**
- Max spacing on walls: 12 feet
- Max distance from door: 6 feet
- Kitchen counters: 4 feet max spacing
- GFCI required: bathrooms, kitchen, exterior, garage, unfinished basement

**Smoke Detectors:**
- One per sleeping room
- One per floor
- In hallway outside sleeping rooms
- Interconnected

**Windows:**
- Bedroom egress: 5.7 sq ft minimum
- Sill height: 44" maximum
- Minimum width: 20"
- Minimum height: 24"

**Ceiling Heights:**
- Minimum: 7 feet (most rooms)
- Minimum: 6'8" (bathrooms, kitchens)

### 8.2 Span Tables (3 pages)

**Floor Joists (40 PSF live load):**
- 2x8 spacing and max spans
- 2x10 spacing and max spans
- 2x12 spacing and max spans

**Ceiling Joists:**
- 2x6, 2x8, 2x10 max spans

**Rafters:**
- Common rafter spans by size and spacing

**Headers:**
- Header size by span width

**Deck Joists:**
- Joist size by span and spacing

### 8.3 Material Calculators (2 pages)

**Concrete:**
- Cubic yards = (length × width × thickness in inches) ÷ 324

**Drywall:**
- Sheets needed = (wall/ceiling area) ÷ 32 (for 4'×8' sheets)

**Paint:**
- Gallons = (area to paint) ÷ 350

**Flooring:**
- Square footage needed = (length × width) × 1.10 (waste factor)

**Siding:**
- Square feet needed = total wall area - window/door areas
